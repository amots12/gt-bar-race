## Tool Notes

| Tool | Notes |
|------|-------|
| Apollo.io | Used for weekly lead list export (CSV). Manual task ~45 min/week. Handles deduplication via Do Not Contact list. |
| La Growth Machine | Replaces Expandi. Cloud-based (safer). Handles Track 1 + Track 2 sequences separately. CSV import from Apollo weekly. |
| LinkedIn Sales Navigator | Core plan. Used for advanced search + InMail for high-priority prospects. Does not replace Apollo — complementary. |
| Cloudflare Pages | Hosts landing pages built by developer. Designer uses Figma for design files (designer brings own tools — not a monthly cost). |

## Landing Page Workflow

```
Designer (Figma) → Developer (builds) → Cloudflare Pages (hosts)
```

- LP-T1 and LP-T2 blueprints ready at agents/landing-page-agent.md
- Brief designer using those specs when engaged
- Activate landing pages before paid ads go live

---

## Lead Flow Workflow (weekly, manual)

```
Apollo saved search → export CSV → remove existing leads (Do Not Contact)
→ split by track (T1 / T2) → import to La Growth Machine → sequence activated
```

Frequency: once per week | Time: ~45 min
